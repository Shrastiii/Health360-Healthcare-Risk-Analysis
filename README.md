# Health360: Comprehensive Healthcare Risk and Disease Analysis

Tableau dashboards analyzing Heart Disease, Diabetes and Stroke risk
to help identify high-risk patients early.

Live dashboard: PASTE YOUR TABLEAU PUBLIC LINK HERE

## Dataset
Synthetic dataset of 5,000 patients and 29 columns (health360_patients.csv),
generated with Python for demonstration. Includes demographics, clinical
indicators (BMI, BP, cholesterol, glucose), lifestyle habits and symptoms.

## Dashboards
1. Clinical Risk Assessment (Dr. Michael Carter): KPIs, risk levels, BP categories, high-risk patients
2. Lifestyle and Behavior Analysis (Emily Rodriguez): smoking, alcohol, exercise and symptoms
3. Population Health Overview (Dr. Priya Nair): age groups, BMI categories, gender, cholesterol
4. Story: Health360 Story

## Key insights
- Heart disease prevalence rises from about 3% (age 18-29) to about 45% (75+)
- Obesity, smoking and low exercise are linked to higher disease rates
- About 770 of 5,000 patients (15%) are classified as high risk

## Tools
Tableau Public, Python (dataset generation), GitHub
